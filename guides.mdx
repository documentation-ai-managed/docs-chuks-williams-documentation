|-------|----------|
| Upload fails | Check file size and format compatibility |

## Code Examples

<CodeGroup tabs="Shell,Python">
  ```bash
# Bulk import documents
for file in docs/*.md; do
  curl -X POST \
    'https://api.chukswilliams.com/v1/documents' \
    -H 'Authorization: Bearer your-api-key' \
    -F "file=@$file" \
    -F 'project_id=your-project-id'
done
  ```
  ```python
import os
from chuks_williams_docs import Client

client = Client(api_key='your-api-key')

# Bulk import Markdown files
for filename in os.listdir('docs'):
    if filename.endswith('.md'):
        with open(f'docs/{filename}', 'r') as f:
            content = f.read()
        client.documents.create(
            project_id='your-project-id',
            title=filename.replace('.md', ''),
            content=content
        )
  ```
</CodeGroup>

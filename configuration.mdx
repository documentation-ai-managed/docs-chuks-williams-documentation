## Configuration Overview

Chuks Williams Documentation offers extensive configuration options to customize your documentation space according to your needs. From project settings to user permissions, this guide covers all available configuration options.

<Callout kind="info">
  Most configuration changes take effect immediately, but some may require a page refresh or project rebuild.
</Callout>

## Advanced Settings

<Callout kind="tip">
  Advanced settings should only be modified by experienced users as they can affect system behavior.
</Callout>

| Setting | Description | Default Value |
|---------|-------------|---------------|
| Cache TTL | How long to cache pages | 3600 seconds |
| Max File Size | Maximum upload size | 10MB |
| Rate Limit | Requests per hour | 1000 |
| Search Index | Rebuild frequency | Daily |

## Code Examples

<CodeGroup tabs="JavaScript,cURL">
  ```javascript
const config = {
  projectId: 'your-project-id',
  settings: {
    theme: 'dark',
    domain: 'docs.yourcompany.com',
    permissions: {
      public: false,
      collaborators: ['admin', 'editor']
    }
  }
};

// Update project configuration
await api.updateProject(config);
  ```
  ```bash
curl -X PUT \
  'https://api.chukswilliams.com/v1/projects/your-project-id/config' \
  -H 'Authorization: Bearer your-api-key' \
  -H 'Content-Type: application/json' \
  -d '{
    "theme": "dark",
    "domain": "docs.yourcompany.com",
    "permissions": {
      "public": false,
      "collaborators": ["admin", "editor"]
    }
  }'
  ```
</CodeGroup>
